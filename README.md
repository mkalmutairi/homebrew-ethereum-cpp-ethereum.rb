# ميزان النبطي — تطبيق فحص وزن الشعر النبطي

تطبيق للهواتف (iOS و Android، ويعمل أيضًا في المتصفح) يُدخل فيه المستخدم الشطر الأول ثم الثاني من البيت،
فيعرض تحت كل شطر مباشرة هل هو **موزون** وعلى أي **بحر**، ويحدد مواضع الخلل، ثم يحكم على **البيت كاملًا**.

## المزايا
- التعرف التلقائي على البحر بمجرد كتابة الشطر (لا حاجة لاختيار البحر مسبقًا).
- يدعم بحور الشعر النبطي المعروفة: المسحوب (مستفعلن مستفعلن فاعلاتن)، الهلالي (الطويل)، الصخري (مفاعيلن مفاعيلن فعولن)، السامري (الرمل)، الهجيني بصوره (الطويل/البسيط، القصير، المجتث، فاعلاتن فعولن)، الحداء والرجز، الرجد (الخبب)، الشيباني/اللويحاني (الهزج الرباعي) والهزج الثنائي والثلاثي، المديد (العرضة)، الممتد، إضافة إلى البحور الفصيحة الأخرى، بزحافاتها وضروبها.
- عرض التقطيع تفعيلةً تفعيلة، مع تلوين التفعيلة المختلّة وتحديد الكلمة التي فيها الخلل (مقطع زائد / ناقص / مخالف).
- إذا كان أحد الشطرين موزونًا، يُحكم على الشطر الآخر بالنسبة لبحره نفسه، ثم يُعطى حكم البيت ككل.
- يقبل النص بلا تشكيل ويقطّعه على نطق اللهجة، ويمكن كتابة الحركات (الشدّة والسكون والتنوين) لتقييد القراءة.
- لصق البيت كاملًا في الخانة الأولى بفاصل `*` أو `/` يوزّعه على الشطرين تلقائيًا.

## التشغيل
يحتاج Node.js (الإصدار 20 أو أحدث):

```bash
npm install
npm start          # ثم امسح رمز QR بتطبيق Expo Go على الهاتف
npm run android    # تشغيل على محاكي/جهاز أندرويد
npm run ios        # تشغيل على محاكي iOS (يحتاج macOS)
npm run web        # تشغيل في المتصفح
```

لبناء نسخة قابلة للتثبيت (APK / IPA) استخدم [EAS Build](https://docs.expo.dev/build/introduction/):

```bash
npx eas build --platform android
```

## اختبار محرّك الوزن
محرّك التقطيع مستقل عن الواجهة (JavaScript خالص) ويمكن اختباره من سطر الأوامر:

```bash
npm test                                            # يشغّل حالات الاختبار
node src/engine/__tests__/run.mjs "يا مرحبا يا مرحبا يا مرحبا"   # تحليل شطر معيّن
```

## بنية المشروع
- `src/engine/phonology.mjs` — تحويل النص إلى مقاطع (متحرك / ساكن) وفق قواعد نطق اللهجة: سقوط ألف الوصل، الحروف الشمسية، التنوين، الشدّة، سكون آخر الكلمة، الألف الفارقة…
- `src/engine/meters.mjs` — مكتبة البحور وتفعيلاتها وزحافاتها.
- `src/engine/scan.mjs` — المطابقة بالبرمجة الديناميكية: يختار أنسب قراءة للنص لكل بحر ويحسب عدد الأخطاء ومواضعها.
- `src/components/` — واجهة التطبيق (خانات الشطرين، بطاقة حكم البيت، عرض التقطيع، قائمة البحور).
- `App.js` — الشاشة الرئيسية.

## كيف يعمل التعرف على البحر؟
1. يُقسَّم الشطر إلى حروف، ويُعطى كل حرف الأوزان الممكنة له في النطق (متحرك، ساكن، أو ساقط) مع تكلفة صغيرة للقراءات الأقل شيوعًا.
2. تُقارن كل القراءات الممكنة بكل أنماط البحور (مع الزحافات) في خطوة واحدة بالبرمجة الديناميكية، فيُختار البحر الذي يطابق النص بلا أخطاء وبأطبع قراءة.
3. إن لم يطابق أي بحر، يُعرض أقرب بحر مع المواضع التي يزيد فيها مقطع أو ينقص أو يخالف.
