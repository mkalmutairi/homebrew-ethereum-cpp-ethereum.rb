# آبار نفط الكويت — التقرير اليومي للآبار

تطبيق للهواتف (iOS و Android، ويعمل أيضًا في المتصفح) يعرض قائمة الآبار وحالتها وإنتاجها.
تُدخَل البيانات **باستيراد ملف Excel يوميًا** من داخل التطبيق، فيحفظ قراءات كل يوم ويبني لكل بئر سجلًا لإنتاجه.
وبديلًا عن ذلك يمكن ربطه برابط Google Sheet يُقرأ تلقائيًا عند كل فتح.

## المزايا
- ملخص أعلى الشاشة: عدد الآبار، مجموع إنتاج النفط، متوسط نسبة الماء، وعدد الآبار في كل حالة (منتج، مغلق، صيانة، اختبار، حقن…)؛ الضغط على الحالة يصفّي القائمة.
- بحث باسم البئر أو الحقل، وتصفية حسب الحقل.
- صفحة لكل بئر فيها كل بياناته، ورسم لإنتاجه في آخر 14 يومًا إذا كان الجدول سجلًا يوميًا، وأي أعمدة إضافية كما هي.
- زر "استيراد Excel": اختر ملف التقرير اليومي من الجهاز أو من المرفقات (البريد، واتساب، OneDrive…). يدعم ‎.xlsx‎ و ‎.csv‎.
- يجد جدول الآبار تلقائيًا حتى لو كان فوقه عنوان التقرير، أو كان في الملف أوراق أخرى، ويتجاهل صف المجموع.
- إن لم يكن في الملف عمود تاريخ تُسجَّل القراءات بتاريخ يوم الاستيراد؛ واستيراد ملف اليوم نفسه مرة ثانية يستبدل قراءاته. تُحفظ آخر 60 يومًا.
- ينبّه إذا لم يُستورد ملف اليوم بعد، ويُظهر تحت البئر تاريخ آخر قراءة إن لم يكن موجودًا في آخر ملف.
- يعمل بدون إنترنت؛ البيانات المستوردة محفوظة على الجهاز فقط.
- قبل أول استيراد تُعرض بيانات تجريبية (أرقام وهمية) مع تنبيه واضح.

## الاستيراد اليومي
1. افتح التطبيق واضغط **استيراد Excel**، ثم اختر الملف.
2. الملف: صف عناوين ثم صف لكل بئر (انظر `wells-template.csv`). العناوين المعروفة بالعربي أو الإنجليزي:
   `اسم البئر، الحقل، المنطقة، الحالة، إنتاج النفط، نسبة الماء، الغاز، الضغط، الخانق، المكمن، التاريخ، ملاحظات`
   (`Well / Well No., Field, Area, Status, Oil (BOPD), Water Cut / W/C %, Gas, THP, Choke, Reservoir, Date, Remarks`).
   أي عمود آخر يظهر في تفاصيل البئر، ويكفي عمود الاسم وحده.
3. ملفات Excel القديمة (‎.xls‎) تُحفظ أولًا بصيغة "مصنف Excel (.xlsx)".

## بديل: ربط جدول مشترك
1. ضع الآبار في Google Sheet بنفس شكل الملف أعلاه.
2. شارك الجدول: مشاركة ← "أي شخص لديه الرابط" (عارض)، أو ملف ← مشاركة ← نشر على الويب ← CSV.
3. الصق الرابط في التطبيق من زر **الإعدادات**، أو ضعه في `src/config.js` (`DEFAULT_DATA_URL`) ليكون الافتراضي لكل من يثبّت التطبيق.

> تنبيه: الرابط المشارك يمكن لأي شخص يملكه قراءة الجدول. لا تضع فيه بيانات سرية للشركة إلا بموافقتها.

لفحص طريقة قراءة ملف معيّن من سطر الأوامر:

```bash
node src/data/__tests__/run.mjs path/to/wells.xlsx
```

## التشغيل
يحتاج Node.js (الإصدار 20 أو أحدث):

```bash
cd koc-wells
npm install
npm start          # ثم امسح رمز QR بتطبيق Expo Go على الهاتف
npm run web        # تشغيل في المتصفح
npm test           # اختبارات قراءة الجدول
```

لبناء نسخة قابلة للتثبيت: `npx eas build --platform android` (أو `ios`).

## بنية المشروع
- `src/data/wells.mjs` — قراءة CSV، إيجاد صف العناوين، التعرف على الأعمدة العربية والإنجليزية، توحيد الحالات، تجميع السجل اليومي لكل بئر، والملخص والتصفية (JavaScript خالص قابل للاختبار).
- `src/data/xlsx.mjs` — قارئ ملفات ‎.xlsx‎ (فك الضغط بمكتبة fflate وقراءة الخلايا والتواريخ).
- `src/data/importer.mjs` — التعرف على نوع الملف واختيار ورقة الآبار.
- `src/data/store.js` — الاستيراد ودمج قراءات الأيام وحفظها على الجهاز، وتحميل الرابط المشترك إن وُجد.
- `src/data/sample.mjs` — البيانات التجريبية.
- `src/components/` — الملخص، صف البئر، صفحة البئر، والإعدادات.
