# آبار نفط الكويت — التقرير اليومي للآبار

تطبيق للهواتف (iOS و Android، ويعمل أيضًا في المتصفح) يعرض قائمة الآبار وحالتها وإنتاجها،
ويقرأ البيانات من جدول (Google Sheet أو ملف CSV) في كل مرة يُفتح، فيكفي تحديث الجدول يوميًا
لتظهر الأرقام الجديدة في التطبيق.

## المزايا
- ملخص أعلى الشاشة: عدد الآبار، مجموع إنتاج النفط، متوسط نسبة الماء، وعدد الآبار في كل حالة (منتج، مغلق، صيانة، اختبار، حقن…)؛ الضغط على الحالة يصفّي القائمة.
- بحث باسم البئر أو الحقل، وتصفية حسب الحقل.
- صفحة لكل بئر فيها كل بياناته، ورسم لإنتاجه في آخر 14 يومًا إذا كان الجدول سجلًا يوميًا، وأي أعمدة إضافية كما هي.
- تحديث تلقائي عند فتح التطبيق وعند الرجوع إليه، وسحب القائمة للأسفل للتحديث يدويًا.
- يعمل بدون إنترنت بآخر بيانات محفوظة، وينبّه إذا كان الجدول لم يُحدَّث منذ أكثر من يوم.
- قبل ربط الجدول تُعرض بيانات تجريبية (أرقام وهمية) مع تنبيه واضح.

## ربط جدول الآبار
1. ضع الآبار في Google Sheet: صف عناوين، ثم صف لكل بئر — أو صف لكل بئر في كل يوم (سجل يومي).
   انظر `wells-template.csv` كمثال. العناوين المعروفة بالعربي أو الإنجليزي:
   `اسم البئر، الحقل، المنطقة، الحالة، إنتاج النفط، نسبة الماء، الغاز، الضغط، الخانق، المكمن، التاريخ، ملاحظات`
   (`Well, Field, Area, Status, Oil (BOPD), Water Cut, Gas, THP, Choke, Reservoir, Date, Notes`).
   أي عمود آخر يظهر في تفاصيل البئر، ويكفي عمود الاسم وحده.
2. شارك الجدول: مشاركة ← "أي شخص لديه الرابط" (عارض)، أو ملف ← مشاركة ← نشر على الويب ← CSV.
3. الصق الرابط في التطبيق من زر **الإعدادات**، أو ضعه في `src/config.js` (`DEFAULT_DATA_URL`) ليكون الافتراضي لكل من يثبّت التطبيق.

> تنبيه: الرابط المشارك يمكن لأي شخص يملكه قراءة الجدول. لا تضع فيه بيانات سرية للشركة إلا بموافقتها.

لفحص طريقة قراءة جدول معيّن قبل ربطه:

```bash
node src/data/__tests__/run.mjs path/to/wells.csv
```

## التشغيل
يحتاج Node.js (الإصدار 20 أو أحدث):

```bash
cd koc-wells
npm install
npm start          # ثم امسح رمز QR بتطبيق Expo Go على الهاتف
npm run web        # تشغيل في المتصفح
npm test           # اختبارات قراءة الجدول
```

لبناء نسخة قابلة للتثبيت: `npx eas build --platform android` (أو `ios`).

## بنية المشروع
- `src/data/wells.mjs` — قراءة CSV، التعرف على الأعمدة العربية والإنجليزية، توحيد الحالات، تجميع السجل اليومي لكل بئر، والملخص والتصفية (JavaScript خالص قابل للاختبار).
- `src/data/store.js` — تحميل الجدول من الرابط، تحويل روابط Google Sheets إلى CSV، والحفظ على الجهاز.
- `src/data/sample.mjs` — البيانات التجريبية.
- `src/components/` — الملخص، صف البئر، صفحة البئر، والإعدادات.
